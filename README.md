# Bus ETA Test

This is a simple web application that displays bus arrival time information for stops around a location picked by the user on a map. 

This project was built as a test of the Gemini CLI to perform software engineering tasks.

## Open Data Source

The project uses the following open data APIs from the Hong Kong government:

- **Stop List Data:** [https://data.gov.hk/en-data/dataset/hk-td-tis_21-etakmb/resource/3d6ded6c-ee36-40a0-a6fe-8f40966dff67](https://data.gov.hk/en-data/dataset/hk-td-tis_21-etakmb/resource/3d6ded6c-ee36-40a0-a6fe-8f40966dff67)
- **Stop ETA Data:** [https://data.gov.hk/en-data/dataset/hk-td-tis_21-etakmb/resource/12185102-718d-4d03-bfd7-b9ecf760aee2](https://data.gov.hk/en-data/dataset/hk-td-tis_21-etakmb/resource/12185102-718d-4d03-bfd7-b9ecf760aee2)
